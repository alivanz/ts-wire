# ts-sse

TypeScript Server-Sent Events.

## Requirements

- Node >= 22
- pnpm

## Setup

```bash
pnpm install
```

## Scripts

| Script            | Does                              |
| ----------------- | --------------------------------- |
| `pnpm dev`        | Run `src/index.ts` in watch mode  |
| `pnpm build`      | Compile to `dist/`                |
| `pnpm start`      | Run built output                  |
| `pnpm typecheck`  | Type-check without emitting       |
| `pnpm clean`      | Remove `dist/`                    |
